🚀 Hướng dẫn Deploy lên GitHub Pages

Bạn hoàn toàn có thể đưa trang web này lên GitHub Pages miễn phí vĩnh viễn với tên miền cực đẹp:

Bước 1: Đăng nhập github.com ➔ Bấm dấu + ở góc phải trên ➔ Chọn New repository.
Bước 2: Đặt tên repo (ví dụ: chiec-binh-cam-xuc), chọn Public ➔ Bấm Create repository.
Bước 3: Trong trang repo vừa tạo, bấm uploading an existing file ➔ Kéo thả file index.html vào ➔ Bấm Commit changes.
Bước 4: Vào tab Settings của repository ➔ Mục Pages ở cột trái ➔ Ở phần Branch, chọn main và bấm Save.
Bước 5: Đợi 1 phút, bạn sẽ có link: https://<tên-bạn>.github.io/chiec-binh-cam-xuc/!
